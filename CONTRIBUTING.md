# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Report a problem or suggest an improvement

Open a GitHub issue with a clear title, the expected behavior, actual behavior, and steps to reproduce. Include sample principal, annual rate, and time values for calculation problems. Never include passwords or other private information.

## Submit a change

1. Fork the repository and create a descriptive branch from `main`.
2. Keep changes focused and follow the existing Bash or JavaScript style.
3. Update documentation and add meaningful tests for changed behavior.
4. Run `bash -n simple-interest.sh`, `python3 -m unittest discover -s tests`, and `node --test calculator.test.js`.
5. Open a pull request explaining the problem, solution, and validation results.

Read [our Code of Conduct](CODE_OF_CONDUCT.md) before participating. Contributions are provided under the project's [Apache License 2.0](LICENSE).
